# MUB 论文审阅意见

审阅日期：2026-10-16  
作者：Kun Liu（founder@tokenspark.uno）  
对应稿件：`main.tex` / `main.pdf`

本次完成了近期文献、作者信息、论文论断和实现一致性的修订。当前版本适合作为待验证的研究草稿；在下述问题解决前，不宜声称已经完成有效的多模态大模型能力比较或版权安全数据发布。

## 1. P0：修复调性指标和评分分母，再重新计算结果

`src/metrics.py` 的相对调性条件为 `(pred_pc + 3) % 12 == gold_pc` 且模式不同。它接受 A minor 对 C major，却拒绝反方向，也会错误接受 C major 对 E-flat minor。论文中的 DSP 25.4% 和常量基线 9.2% 已明确标为 legacy 分数，不能称为标准调性准确率。

建议以 tonic/mode 完全匹配为主指标；相对大小调分数仅作为单独定义的辅助指标。对同一批已保存预测按正确的对称相对调性规则重算为 DSP 29.4%、常量基线 11.0%，这些诊断值不等于已经修复评分器。均匀随机预测下，完全匹配机会水平为 1/24，完全或相对匹配为 2/24。

聚合器还会忽略缺失预测、跳过未知 ID，并重复计入重复 ID。应验证恰好覆盖 500 个 ID，以全量分母计失败，并显式拒绝重复/未知 ID。现有两份基线各有 500 个唯一有效 ID，因此其既有汇总未受漏行问题影响。修改后需要独立指标版本和回归测试，不能静默覆盖旧分数。

## 2. P0：补充录音与标注授权，不能以去标题代替版权核查

选择脚本没有逐曲许可字段、版权风险排序或标注再分发授权检查，因而尚未满足“版权风险最小的 500 首”的原始目标。不分发音频可减少再分发行为，但不能证明录音的评测使用或标注发布已获授权。原 README 的 CC BY-SA 4.0 数据许可缺少依据，已在文档中撤回该无证据声明；这不是对历史许可法律效力的判断。

建议建立私有权利清单，区分作品、录音、标注的权利与用途，记录来源、许可证据、评测/再分发范围及撤回机制，再按明确规则确定可发布子集。元数据字符串去重也不能保证 500 首不同作品；需要检查版本、别名与音频重复。当前稿件已明确这些边界，没有虚构权利清算结果。

## 3. P1：增加独立标注可靠性证据

上游使用最后一次提交，再对段落属性取众数；独占众数不等于严格多数，更不等于多人一致。500 条中 399 条只记录一个 operator，117 条只有一次 submission。当前选择器没有强制完成质检状态。修订稿已移除“全部通过 QC”“多人交叉验证”等无证据表述。

建议对 BPM、大小调、非 4/4、复杂结构进行分层抽样双人独立复标与仲裁，报告各任务的一致性、分歧和置信区间。检查 BPM 字符串解析、转调/变拍等多解情况，保留不确定参考或允许替代有效答案，而不是仅靠一个全局众数。

## 4. P1：补做受控 MLLM 实验和结构基线

本轮没有运行 Audio Flamingo 3、Music Flamingo 或其他 MLLM。当前 DSP 和常量基线均不输出任何结构段落，结构 F1=0 仅表示未作答，不能证明 DSP 无法分段，也不能推出正分代表语义理解。

建议在修复评分后，选取有合法音频访问路径的模型，统一完整音频覆盖、上下文长度、切块、采样参数和重试政策；至少比较有音频、无音频、简单 DSP 与一个能输出边界的结构基线。记录模型版本、日期、失败率和实际工具配置。本次只审阅并修正文稿，没有启动收费模型评测或新增外部上传。

## 5. P1：结构评估与拍号分布需要增强

当前结构分数忽略 label，只做 IoU≥0.5 的贪心匹配；未实现独立标签准确率、边界容差分数或完整区间合法性检查。少量区间并不能证明贪心等价于最优匹配。建议分别报告边界、区间、语义标签表现，定义重叠、间隙、越界、无穷值及无效输出的处理规则。

拍号分布为 492/500 的 4/4，另外两类各四条，常量 4/4 即得 98.4%。建议补充逐类召回、混淆矩阵、balanced accuracy 或 macro-F1，并增加非 4/4 样本；当前罕见类别样本太少，需要披露统计不确定性。

## 6. P1：把身份隐藏和工具禁用落实到评测输入

`audio_hash` 是文件前 1,048,576 字节的 SHA-256 截断至 64 bit，不是完整校验和或匿名性保证。生成的 JSONL 仍包含此 evaluator-side 字段；若整体发送模型，可能引入关联查询线索。应只转发音频和 task prompt，清理嵌入标签、文件名、路径，并保持金标准隔离。

提示词本次已明确禁止网络搜索、联网、下载、代码执行、任何外部工具、外部 DSP、指纹识别、音乐识别和数据库查询，并重新生成五份各 500 条的 prompt 文件。但提示词无法强制执行禁令，评测 harness 必须关闭工具/网络；也无法通过指令消除参数内的熟悉录音记忆。当前没有这样的强制执行 harness，论文已将其写成待满足的协议条件。

## 7. P2：收敛贡献定位，并完善可复现发布
